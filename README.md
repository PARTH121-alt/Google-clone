# Google Search Page Clone

A simple **Google Search Page Clone** built using **HTML** and **CSS**. This project replicates the basic layout and design of Google's homepage, including the logo, search bar, and action buttons.

## 🚀 Features

* Responsive Google-inspired homepage layout
* Search bar with clean styling
* "Google Search" and "I'm Feeling Lucky" buttons
* Built using only HTML and CSS
* Beginner-friendly project structure

## 🛠️ Technologies Used

* HTML5
* CSS3

## 🔧 Installation

1. Clone the repository:

```bash
git clone https://github.com/PARTH121-alt/google-search-clone.git
```

2. Open the project folder:

```bash
cd google-search-clone
```

3. Open `index.html` in your browser.
